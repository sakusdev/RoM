RoM releases do not include the official Minecraft client, server JAR, textures, sounds, or other game assets. `rom-bootstrap` obtains the official server artifact directly from an official Mojang/Microsoft endpoint on the user's machine, verifies it against official metadata, and stores it only in the local instance cache.
